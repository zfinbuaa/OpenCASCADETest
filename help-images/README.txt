帮助示意图存放目录

每个功能对应一个子文件夹，文件夹内按数字编号命名图片（1.png, 2.png, 3.png...）。
图片建议分辨率 1200x750，PNG 格式。

目录结构示例：

  01-compare/               数模对比
    1.png
    2.png
    ...

  02-clean/                 数模清洗
    1.png
    2.png
    ...

  03-position/              位置图
    1.png
    2.png
    ...

  04-explosion/             爆炸图
    1.png
    2.png
    ...

  05-serviceability/        拆装方案（可维修性）
    1.png
    2.png
    ...

  06-manual/                拆装方案（维修手册）
    1.png
    2.png
    ...

打包后这些文件夹会自动复制到 release/win-unpacked/resources/help-images/ 目录中。
